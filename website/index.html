Reasoning Modes

Six Ways to Think

Same prompt, different reasoning strategies. Compare how the model's thinking changes.

Default

MiMo's natural reasoning style. Balanced exploration with self-correction.

Step-by-Step

Explicit sequential breakdown. Numbered steps, clear progression from premise to conclusion.

Socratic

Self-questioning approach. The model asks itself clarifying questions and challenges assumptions.

Adversarial

Argues both FOR and AGAINST before synthesizing. Strongest for controversial or nuanced topics.

ELI5

Simple analogies and concrete examples. Great for understanding complex concepts quickly.

Academic

Formal logical structure, precise definitions, citations. For rigorous analysis.

Get Started

Install in 30 Seconds

Python 3.10+ required. One command to install, one to run.

# Clone the repo
git clone git@github.com:ertesemedo04-dev/mimo-reasoning-playground.git
cd mimo-reasoning-playground

# Install
pip install -e .

# Configure API key
cp .env.example .env
# Edit .env with your MIMO_API_KEY

# Launch web UI
mimo-playground web

# Or use CLI
mimo-playground list # see all challenges
mimo-playground run logic-001 # run a challenge
mimo-playground chat # interactive mode
API

Use in Your Code

Async Python client with streaming support. Integrate reasoning traces into any app.

import asyncio
from mimo_playground.client import MiMoClient

client = MiMoClient(
    api_base="https://api.xiaomi.com/v1",
    api_key="your-key",
)

async def main():
    async for event in client.stream_reasoning("Explain quantum entanglement"):
        if event["type"] == "reasoning":
            print(event["content"], end="")
        elif event["type"] == "answer":
            print(event["content"], end="")

asyncio.run(main())
